# Politique de sécurité

## Signaler une faille

Ne signalez **jamais** une faille dans un ticket public, une discussion ou une pull request.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt concerné, puis bouton
**Report a vulnerability**. Votre signalement n'est visible que par l'équipe de PolygonLab.

Merci d'indiquer :

- le dépôt et la version concernés ;
- la nature de la faille et son impact possible ;
- les étapes pour la reproduire, avec un exemple minimal si possible.

## Ce que nous nous engageons à faire

- Accuser réception de votre signalement sous **5 jours ouvrés**.
- Vous tenir informé de l'analyse et de la correction.
- Publier une version corrective, puis un avis de sécurité, et vous créditer si vous le
  souhaitez.

## Versions maintenues

Seule la **dernière version publiée** de chaque dépôt reçoit les correctifs de sécurité.

## Récompense

Nos dépôts n'offrent pas de programme de récompense.

## In English

Never report a vulnerability in a public issue. Use GitHub private vulnerability reporting
(Security tab, "Report a vulnerability"). We acknowledge reports within 5 business days.
Only the latest release of each repository is supported. There is no bug bounty.
